# F0218: type does not implement the required trait

`no-trait-impl` · always an error

A generic fn bound by a user trait (`fn f<T: MyTrait>`) was instantiated
with a type that has no `impl MyTrait for ...` block — or a trait call
named a type/trait pair with no impl.

```freshet
trait Numeric { fn add(a: Self, b: Self) -> Self; }
impl Numeric for i64 { fn add(a: Self, b: Self) -> Self { return a + b; } }

fn twice<T: Numeric>(x: T) -> T { return Numeric::add(x, x); }

fn main() {
    let r: bool = twice(true);   // error[F0218]: bool implements no Numeric
    print_i64(r as i64); println();
}
```

**Fix:** add `impl Numeric for bool { ... }`, or instantiate with a type
that already implements the trait.
