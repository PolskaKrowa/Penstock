# F0213: break or continue outside a loop

`loop-break-outside` · always an error

`break;` and `continue;` bind to the innermost enclosing `for` or `while`
loop. Using them anywhere else is an error.

```freshet
fn main() {
    break;   // error[F0213]
}
```

**Fix:** remove the statement, or move it inside the loop it is meant for.
Directly inside a `parfor` body they follow different rules; see the
language spec.
