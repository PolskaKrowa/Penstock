# F0404: hot field straddles a cache line

`cache-line-straddle` · warning by default · error with `--strict-performance` / `@hpc_strict`

A field used inside a hot loop crosses a 64-byte boundary, so about half
of the accesses touch two cache lines. This is only reported when the
array base is not guaranteed to be 64-byte aligned and the field is
smaller than a cache line.

```freshet
struct T { a: u32, b: u32, c: u32 }          // 12 bytes
struct S { t1: T, /* ... */ t12: T }
fn main() {
    let arr: *S = malloc(S, 256);
    parfor (i in 0..256) { arr[i].t6.a = 1; }  // field straddles a 64B line
    free(arr);
}
```

**Fix:** declare the struct `align(64)`, or reorder its fields. The message
names the struct, the field, and its offset and size.
