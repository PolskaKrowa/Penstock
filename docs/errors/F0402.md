# F0402: division by a runtime value

`arith-div-runtime` · warning by default · error with `--strict-performance` / `@hpc_strict`

Integer division or remainder by a value only known at run time has a
latency of roughly 20-40 cycles and is not pipelined, so a hot loop
containing it is slow. Float division is not affected.

```freshet
fn main() {
    let d: i64 = 0;
    let x: i64 = 100;
    let r: i64 = x / d;   // warning[F0402] (error under --strict-performance)
}
```

**Fix:** hoist the divisor to a power-of-2 constant, or restructure so the
division leaves the hot loop.

This is the same ID in every mode; only the severity changes. See also
[F0401](F0401.md).
