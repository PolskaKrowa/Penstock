# F0405: for-loop stride is not constant 1

`loop-stride` · warning by default · error with `--strict-performance` / `@hpc_strict`

A C-style `for` loop whose step is not the constant `1` still compiles and
runs correctly (the lowering honours the step), but vectorization
guarantees are lost.

```freshet
for (i = 0; i < 10; i += 3) { /* ... */ }   // warning[F0405]
```

**Fix:** use a nested loop or manual blocking for strides other than 1.
A different problem with the same flavour is [F0406](F0406.md).
