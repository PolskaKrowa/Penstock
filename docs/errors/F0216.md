# F0216: trait method call does not determine its implementing type

`trait-call-ambiguous` · always an error

A `Trait::method(...)` call cannot pick an impl: no argument names a type
that implements the trait (or several traits provide the same method for
a type-qualified call). Static dispatch needs a concrete implementing
type at the call site.

```freshet
trait Seed { fn zero() -> Self; }
impl Seed for i64 { fn zero() -> Self { return 0; } }
impl Seed for f64 { fn zero() -> Self { return 0.0; } }

fn main() {
    let z: i64 = Seed::zero();   // error[F0216]: which zero()?
}
```

**Fix:** call the method where the type is determined — pass a
`Trait`-typed argument (`Seed::zero` with one trait only per type also
works), call it inside a generic fn bound by the trait, or inside an
`impl` block via `Self::zero()`.
