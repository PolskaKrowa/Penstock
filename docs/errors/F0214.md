# F0214: division by zero

`arith-div-zero` · always an error

Dividing (or taking a remainder) by the literal `0` is rejected at compile
time. This is a correctness error, so `--strict-performance` makes no
difference.

```freshet
fn main() {
    let x: i64 = 100;
    let r: i64 = x / 0;   // error[F0214]: division by zero
}
```

**Fix:** use a non-zero divisor. If the divisor is only zero at run time,
that is not this diagnostic (division by zero then traps at run time; see
the numeric semantics section of the language spec).
