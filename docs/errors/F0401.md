# F0401: division by a non-power-of-2 constant

`arith-div-const` · warning by default · error with `--strict-performance` / `@hpc_strict`

Integer division and remainder by a constant that is not a power of two
cost roughly 20-40 cycles and are not pipelined. Division by a power of
two compiles to a shift. The program is correct either way, which is why
this is a warning unless the strict HPC policy is on.

```freshet
let r: i64 = x / 10;   // warning[F0401]
```

**Fix:** divide by a power of two, or strength-reduce it yourself by
multiplying by a reciprocal constant. For a divisor that is not a
compile-time constant, see [F0402](F0402.md). Division by the literal `0`
is [F0214](F0214.md).
