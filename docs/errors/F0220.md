# F0220: compile-time assertion failed

`const-assert` · always an error

`const_assert(expr)` evaluated its argument at compile time and the
result was false.  The compile stops; the assertion generates no runtime
code.

```freshet
const fn square(x: usize) -> usize { return x * x; }

fn main() {
    const_assert(square(5) == 24);   // error[F0220]: 25 != 24
    print("unreachable"); println();
}
```

**Fix:** correct the expression or the assertion — the diagnostic is the
compile-time equivalent of a failing unit test.
