# F0219: expression is not const-evaluable

`const-eval` · always an error

A const-generic argument, array length or `const_assert` operand did
not reduce to a compile-time usize value.  Const evaluation supports
integer literals, const generic parameters, arithmetic/comparison
operators over those, and calls to `const fn`s (loops included, budget
capped).  Runtime calls, unknown names, division by zero and
zero-length arrays fail.

```freshet
struct Vector<T, const N: usize> { data: [T; N] }
fn input() -> usize { return 4; }

fn main() {
    // error[F0219]: input() is not a const fn
    let v: Vector<f64, input()> = Vector { data: [1.0] };
}
```

**Fix:** mark the function `const fn`, or build the value from literals
and const parameters (e.g. `Vector<f64, 4>` or `Vector<f64, 2 * 2>`).
