# F0217: impl block does not match the trait declaration

`trait-impl-mismatch` · always an error

Every member of an `impl Trait for Type` block must exist in the trait
and match its declared signature: same parameter count, same types (with
`Self` bound to the impl's target), same return type.

```freshet
trait Numeric {
    fn add(a: Self, b: Self) -> Self;
    fn zero() -> Self;
}
impl Numeric for f64 {
    fn add(a: Self, b: f64) -> Self { return a + b; }  // ok (Self = f64)
    fn zero() -> f32 { return 0.0; }                   // error[F0217]: return is f32
    fn bogus() -> Self { return 0.0; }                 // error[F0217]: not in the trait
}

fn main() {}
```

**Fix:** make the member's signature identical to the trait's after
`Self` substitution, and remove members the trait does not declare.
