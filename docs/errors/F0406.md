# F0406: loop induction variable modified in the body

`loop-iv-written` · warning by default · error with `--strict-performance` / `@hpc_strict`

Assigning to the loop's induction variable inside the loop body is
correct (the loop still runs as written) but prevents vectorization.

**Fix:** copy the induction variable into a separate `let mut` and modify
that, or restructure the loop so the step is expressed in the loop header.
